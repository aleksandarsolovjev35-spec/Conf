# Сайт конференции НМСТ 2026

Статический сайт: главная страница + страница фотобанка. Без сборки —
достаточно открыть `index.html` или отдать папку любым веб-сервером.

Конференция: **IV Ежегодная научно-практическая конференция «Технологии
микросистем, корпусирования и сборки ЭКБ»**, 17 декабря 2026, НИУ МИЭТ.

## Структура проекта

```
index.html          — главная страница (только разметка)
photos.html         — страница фотобанка (только разметка)
favicon-подобные иконки — images/logos/favicon-32.png, favicon-180.png

images/
  hero/             — фон первого экрана (webp + jpg, отдельная
                      мобильная версия hero-bg-mobile.*)
  logos/            — логотип МИЭТ (белый и синий варианты), favicon

css/                — стили, по одному файлу на ответственность:
  base.css            — переменные, сброс, типографика, контейнер, кнопки,
                        фоны секций
  header.css          — навигация, главный экран (фон, логотипы), подвал,
                        кнопка «наверх»
  about.css           — секция «О конференции» и тематические направления
  speakers.css        — секция «Спикеры» (организации-докладчики)
  program.css         — секция «Программа»
  partners.css        — секция «Партнёры и спонсоры» (два уровня)
  registration.css    — секция «Регистрация» и форма Битрикс24
  contacts.css        — секция «Контакты», адрес площадки, доп. контакты
  media.css           — блоки «Видео о конференции» и «Публикации»
  photobank-teaser.css — блок «Фотобанк» и карусель на главной
  photobank.css       — страница фотобанка: шапка, поиск, сетка альбомов
  photobank-album.css — открытый альбом: мозаика фото и лайтбокс
  animations.css      — появление элементов, «шторка» заголовков,
                        переход между страницами (@view-transition)
  responsive.css      — адаптив (<=1024/900/768/480px), reduced-motion, печать

js/                 — скрипты, подключаются в конце страниц в этом порядке:
  common.js   — меню, навбар при прокрутке, «наверх», плавные якоря,
                анимация перехода между страницами, светлая шапка
                (`<body data-navbar="light">`, используется в photos.html)
  reveal.js   — ядро поочерёдного появления элементов по секциям:
                initReveal(селекторы, onReveal) + страховка: если
                IntersectionObserver не сработал, через 2.5 с показывается всё
  home.js     — главная: счётчики статистики, запуск reveal, карусель
  photobank.js — фотобанк: запуск reveal, поиск/фильтры, данные альбомов
                (объект ALBUMS), мозаика и лайтбокс
  video.js    — превью видеоролика: iframe подгружается только по клику
                (пока data-video-url пуст — кнопка неактивна)

docs/
  plan-dorabotki-2026.md — разбор предложений по доработке и статус пунктов

nmst-2026.ics       — событие для календаря (кнопка «В календарь» на первом экране)
robots.txt          — индексация, ссылка на карту сайта
sitemap.xml         — карта сайта (2 страницы)
images/og-cover.jpg — обложка 1200×630 для соцсетей и мессенджеров
```

## Порядок подключения (важен для каскада)

CSS: `base → header → секции → media → photobank-* → animations → responsive`.
JS: `common → reveal → home/photobank`.
Каждая страница подключает только нужные ей модули (см. `<head>` и конец `<body>`).

## Частые задачи

- **Поменять текст/дату/спикера** — правьте только HTML, в файлах есть
  комментарии-подсказки.
- **Заменить фон первого экрана** — положить новые файлы в `images/hero/`
  (`hero-bg.webp` + `hero-bg.jpg` и мобильные `hero-bg-mobile.*`) под теми же
  именами: разметка менять не нужно.
- **Добавить официальные логотипы** — файлы в `images/logos/` (МИЭТ) и
  `images/partners/` (партнёры); в разметке заменить текстовые карточки
  `.partner-logo` / `.partner-name` на `<img src="images/partners/...">`.
- **Добавить альбом фотобанка** — карточка в `photos.html` + запись в `ALBUMS`
  (`js/photobank.js`).
- **Заменить заглушки на фото** — в `ALBUMS` добавить адреса файлов;
  миниатюры в мозаике собирает `photobank.js`.
- **Форма регистрации** — встроенная форма Битрикс24 в секции `#registration`
  (`index.html`). Заголовок формы скрыт стилями; вопрос про ДПО добавляется
  в личном кабинете `bo.miet.ru`, не в этом репозитории.

## SEO, календарь и доступность

- Микроразметка `schema.org/Event` в `<head>` главной: дата, место, бесплатное
  участие. Проверяется в `tests/content.spec.js`.
- OG/Twitter-карточка: `images/og-cover.jpg` (1200×630). При смене даты или
  места обложку нужно перегенерировать.
- Кнопка «В календарь» отдаёт `nmst-2026.ics` (UTC+3, напоминание за сутки).
  При переносе даты правится и файл, и `DTSTART`/`DTEND` в микроразметке.
- `<main>`, ссылка «Перейти к содержанию» (видна только при фокусе),
  подсветка текущего раздела в меню.
- `robots.txt` и `sitemap.xml` — **перед публикацией заменить `https://miet.ru/`
  на итоговый домен** (он же в `og:url`, `canonical`, `sitemap.xml`).

## Мобильная версия и проверка адаптива

Общие адаптивные правила находятся в `css/responsive.css`: меню сворачивается
при ширине до 1024 px, основные секции переходят в одну колонку до 768 px,
альбомы — до 560 px. На экранах до 480 px дополнительно уменьшаются отступы.
Закрытое мобильное меню исключено из фокуса; открытое закрывается по Escape,
клику вне навигации, выбору ссылки и переходу к настольной ширине.

Для запуска браузерных регрессионных проверок (Node.js и Python 3):

```sh
npm ci
npx playwright install --with-deps chromium
npm test
```

Тестовый сервер запускается автоматически. Проверяются обе страницы на ширинах
320–1280 px, меню, карусель, поиск и просмотр альбома в двух ориентациях,
а также контентные требования (`tests/content.spec.js`): год 2026 на обеих
страницах, иерархия заголовков первого экрана, направления, партнёры,
программа, новые блоки и видимость контента без JavaScript.
Внешние шрифты и форма Битрикс24 в автотестах отключены: загрузку и внутреннюю
вёрстку сторонней формы следует дополнительно проверять с доступом к `bo.miet.ru`.
Для готового локального Chromium можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.
Сайт остаётся статическим: Node.js нужен только для тестов, не для публикации.
