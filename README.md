# Сайт конференции НМСТ 2025

Статический сайт: главная страница + страница фотобанка. Без сборки —
достаточно открыть `index.html` или отдать папку любым веб-сервером.

## Структура проекта

```
index.html          — главная страница (только разметка)
photos.html         — страница фотобанка (только разметка)
images/             — изображения (partners/, speakers/)

css/                — стили, по одному файлу на ответственность:
  base.css            — переменные, сброс, типографика, контейнер, кнопки
  header.css          — навигация, главный экран, подвал, кнопка «наверх»
  about.css           — секция «О конференции»
  speakers.css        — секция «Спикеры»
  program.css         — секция «Программа»
  partners.css        — секция «Партнёры и спонсоры»
  registration.css    — секция «Регистрация» и форма Битрикс24
  contacts.css        — секция «Контакты»
  photobank-teaser.css — блок «Фотобанк» и карусель на главной
  photobank.css       — страница фотобанка: шапка, поиск, сетка альбомов
  photobank-album.css — открытый альбом: мозаика фото и лайтбокс
  animations.css      — появление элементов, «шторка» заголовков,
                        переход между страницами (@view-transition)
  responsive.css      — адаптив (<=1024/768/480px), reduced-motion, печать

js/                 — скрипты, подключаются в конце страниц в этом порядке:
  common.js   — меню, навбар при прокрутке, «наверх», плавные якоря,
                анимация перехода между страницами (обе страницы)
  reveal.js   — ядро поочерёдного появления элементов по секциям:
                initReveal(селекторы, onReveal)
  home.js     — главная: счётчики статистики, запуск reveal, карусель
  photobank.js — фотобанк: запуск reveal, поиск/фильтры, данные альбомов
                (объект ALBUMS), мозаика и лайтбокс
```

## Порядок подключения (важен для каскада)

CSS: `base → header → секции → photobank-* → animations → responsive`.
JS: `common → reveal → home/photobank`.
Каждая страница подключает только нужные ей модули (см. `<head>` и конец `<body>`).

## Частые задачи

- **Поменять текст/дату/спикера** — правьте только HTML, в файлах есть комментарии-подсказки.
- **Добавить альбом фотобанка** — карточка в `photos.html` + запись в `ALBUMS` (`js/photobank.js`).
- **Заменить заглушки на фото** — в `ALBUMS` добавить адреса файлов; миниатюры в мозаике собирает `photobank.js`.
- **Форма регистрации** — встроенная форма Битрикс24 в секции `#registration` (`index.html`).

## Мобильная версия и проверка адаптива

Общие адаптивные правила находятся в `css/responsive.css`: меню сворачивается
при ширине до 1024 px, основные секции переходят в одну колонку до 768 px,
альбомы — до 560 px. На экранах до 480 px дополнительно уменьшаются отступы.
Закрытое мобильное меню исключено из фокуса; открытое закрывается по Escape,
клику вне навигации, выбору ссылки и переходу к настольной ширине.

Для запуска браузерных регрессионных проверок (Node.js и Python 3):

```sh
npm ci
npx playwright install --with-deps chromium
npm test
```

Тестовый сервер запускается автоматически. Проверяются обе страницы на ширинах
320–1280 px, меню, карусель, поиск и просмотр альбома в двух ориентациях.
Внешние шрифты и форма Битрикс24 в автотестах отключены: загрузку и внутреннюю
вёрстку сторонней формы следует дополнительно проверять с доступом к `bo.miet.ru`.
Для готового локального Chromium можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.
Сайт остаётся статическим: Node.js нужен только для тестов, не для публикации.
