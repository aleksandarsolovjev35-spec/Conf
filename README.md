# Сайт конференции ТМКС-2026 (НМСТ / НИУ МИЭТ)

Статический сайт III Ежегодной научно-практической конференции «Технологии микросистем, корпусирования и сборки ЭКБ» (17 декабря 2026, НИУ МИЭТ, Зеленоград).

Сайт не требует сборки, серверного окружения или сторонних зависимостей — все пути относительные, проект готов к размещению на любом веб-сервере (Nginx, Apache, IIS, статический хостинг) как в корне домена, так и в поддиректории.

## Размещение на сервере

1. Скопируйте содержимое репозитория в целевую директорию веб-сервера.
2. При размещении на итоговом домене обновите базовый URL `https://miet.ru/` на фактический адрес сайта в трёх файлах:
   - `index.html` (`og:url`, `canonical` и блок `application/ld+json`);
   - `robots.txt` (`Sitemap`);
   - `sitemap.xml` (`<loc>`).

## Локальный просмотр

Для локальной проверки достаточно любого статического HTTP-сервера, например:

```bash
python3 -m http.server 8000
```

После запуска сайт доступен по адресу `http://localhost:8000`.
