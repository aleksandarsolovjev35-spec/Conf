# Логотипы партнёров

Официальные знаки организаций-партнёров конференции. Файлы приведены к одной
высоте (64–220 px) и очищены от полей; пропорции не менялись.

| Файл | Организация | Откуда взят |
|---|---|---|
| `zntc.png` | АО «ЗНТЦ» | профиль компании, [zntc.ru](https://zntc.ru/) |
| `sovtest-ate.png` | ООО «Совтест АТЕ» | каталог выставки CEMAT Russia |
| `t1.png` | Т1 Интеграция | профиль компании на career.habr.com |
| `eremex.png` | ЭРЕМЕКС | [официальная страница логотипов](https://www.eremex.ru/about/logos/) |
| `ostec.png` | ООО «Остек-ЭК» | профиль компании, [ostec-group.ru](https://ostec-group.ru/) |

## Требования к новым файлам

- Прозрачный фон (PNG или SVG) либо ровный белый — карточки белые.
- Ширина от 600 px для широких логотипов: на экранах с высокой плотностью
  мелкий файл выглядит мыльным.
- Полный знак: у большинства организаций запрещено использовать отдельно
  графический знак или отдельно шрифтовую часть.
- Имя файла — латиницей, через дефис: `sovtest-ate.png`.

## Как добавить

1. Положить файл в эту папку.
2. В `index.html` в блоке `#partners` добавить карточку:

```html
<div class="partner-logo">
    <img src="images/logos/partners/имя-файла.png" alt="Название организации"
         width="640" height="210" loading="lazy">
</div>
```

`alt` обязателен: для логотипа это единственное текстовое представление
названия. Логотипы в карточках спикеров (`#speakers`) добавляются так же —
`<img>` внутрь `.speaker-brand`, название остаётся в `.speaker-name`
и скрывается визуально.
